## Added or changed during the merge
- **Next 16 params:** dynamic routes use async `params` (`Promise<...>`). The admin blog editor uses `useParams()`.
- **Button:** `components/Button.tsx` is `'use client'` again, because the demo-modal `onClick` needs it. The duplicate `cta_click` was removed; the delegated listener in `Analytics.tsx` already sends it.
- **Plan in the demo modal:** the modal carries the plan picked on /pricing (`vehicles`, `currency`, `billing`) into the form. `/demo?vehicles=…` keeps these params when it redirects.
- **Analytics:** GA4 (`NEXT_PUBLIC_GA_ID`) and GTM load in production behind Consent Mode v2. `NEXT_PUBLIC_ENABLE_GTM=false` turns both off.
- **Canonical host:** `redirects.js` 308s `www.axpense.net` and the Vercel domain to `NEXT_PUBLIC_SITE_URL` when `ENFORCE_CANONICAL_HOST=true`.
- **Sitemap:** `/demo` is excluded, and the SEO audit skips `/demo` links.
- **Dependencies:** `package-lock.json` was updated for `tsx`, which the `seo:content` script uses.
